Week 9: Networking

For this assignment, I worked on an internet-connected magic card printer. I wanted to play a Magic format called Momir basic, where you play with random cards. However, it's really only feasible on digital because physical random cards are hard to randomly create. That is, unless you connect a thermal printer to an esp32, which allows access to the Scryfall random cards api, which I then filtered to get a random card from a desired category. For example, in Momir basic the search terms would be looking for only creature cards of a specific mana value, specifically a mana value equal to the mana a player used to cast the random card. Because Scryfall only takes HTTPS requests, I had to use both WiFiClientSecure client; //and HTTPClient http; to create a secure connection and send the actual GET requests for the data. Then, I used ArduinoJson to parse the recieved data for the name, type, power, toughness, oracle text (body), and mana cost, which I then printed to the printer using TTL serial (UART) interface Serial1.
