Week 5: 3D Printing

3D Print

This week, I designed and printed the jaws from a small servo-driven claw I designed originally for use in FTC robotics during the INTO THE DEEP season. They use opposing herringbone gears for auto-alignment as well as some inset holes for bearings and a servo horn from goBILDA. This claw was quite effective as it allowed us to accurately pick up the game objects for that year's game. I think they are an interesting part to 3D print because the herringbone gear profile would be difficult to reproduce without very specialized equipment.

Here's the file downloads for the part: STEP, 3MFs, and gcode(MK3S+).

3D Scan

Truthfully, I had some difficulty with this 3D scan, but I attempted to 3D scan a box of cards as a simple object that has visible patterns for scanning. I thought the shiny top might have had some trouble but it seemed to work out okay. However, there is no bottom or back to the model, I think the pull tab caused some issues with the back face. But, it did capture the patterns on the top of the box. It also seems to have made the box shorter than it was in real life, but that's okay.
