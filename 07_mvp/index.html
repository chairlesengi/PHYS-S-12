Week 7: MVP

For my MVP, I built a closed-loop position feedback actuator using a stepper driver and a AS5600 12 bit magnetic angle sensor. It reads the sensor, determines the error between where it is and where it wants to be, and generates a proportional response signal. The actuator also has a 12:1 cycloidal drive reducer gearbox that multiplies the torque of the motor, while reducing its speed. The sensor connects over I2C, communicating the absolute angle of the stepper motor within one degree. Then, a custom AS5600Sensor class measures and keeps track of the position of the stepper over multiple rotations, up to 12000 rpm or so. A orchestrator 'Actuator' class then handles the feedback loop, commanding control into a modular motor class. I connected the motor driver according to the default pololu driver connection and the as5600 like any other i2c device, using the Adafruit AS5600 library. The full libary can be found here. Measurement and Oscilloscope

I also used an oscilloscope to measure the SDA signal for the I2C angle sensor which I saw was frames of binary data that operates in the 10s to 100s of kHz for data rates. I also used the oscilloscope for other debugging throughout this MVP, like when I checked all my wiring and signals after having 3 bad drivers in a row.

Next Steps

I would say the biggest next step is working on better packaging and efficiency of the cycloidal drive, since a lot of the torque is being lost in the drive's inefficiencies, there could be a lot done to make it better. Additionally, I plan on creating a custom driver board that uses hybrid FOC to control the motor and that should be able to make it more powerful and smoother.
